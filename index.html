Política de Privacidade

Última atualização:

1. Quem somos

MEGA utiliza este sistema para controle interno de estoque, compras, vendas e orçamentos de motores elétricos. Esta política explica como os dados inseridos no sistema são tratados.

2. Quais dados são coletados

  • Dados de acesso: e-mail de login (autenticado pelo Supabase Auth) e as permissões de tela associadas a ele. As senhas são gerenciadas diretamente pelo Supabase Auth e não ficam armazenadas dentro deste sistema;
  • Dados operacionais: motores, estoque, compras, vendas e orçamentos;
  • Dados de clientes: nome, CNPJ/CPF, endereço, telefone e e-mail, quando informados;
  • Dados da empresa: razão social, CNPJ, endereço e contato, usados nos PDFs de orçamento.

3. Finalidade

Os dados são usados exclusivamente para a gestão interna do negócio (controle de estoque, emissão de orçamentos e cobrança) e não são vendidos, alugados ou compartilhados com terceiros para fins de marketing.

4. Onde os dados ficam armazenados

Os dados ficam salvos localmente no dispositivo utilizado (armazenamento do navegador) e, quando a sincronização em nuvem está ativa, também em um banco de dados na Supabase, permitindo acesso pelos usuários autorizados a partir de outros dispositivos.

5. Segurança

O acesso ao sistema é feito por login oficial (Supabase Auth), com senha individual de cada usuário gerenciada pelo próprio Supabase — este sistema nunca armazena senhas. Para que essa proteção seja efetiva, o acesso aos dados na nuvem deve ficar restrito a usuários autenticados (Row Level Security no Supabase). Nenhum sistema é 100% livre de risco, mas essas medidas reduzem significativamente a chance de vazamento de dados.

6. Compartilhamento com terceiros

Os dados não são compartilhados com terceiros, exceto quando exigido por lei ou ordem judicial, ou com provedores estritamente necessários à operação do sistema (ex.: Supabase, como infraestrutura de armazenamento em nuvem).

7. Direitos do titular (LGPD)

Qualquer pessoa cujos dados estejam cadastrados no sistema (ex.: um cliente) pode solicitar a confirmação, correção, portabilidade ou exclusão de seus dados, entrando em contato pelos canais informados abaixo.

8. Contato

Em caso de dúvidas sobre esta política ou sobre os dados armazenados, entre em contato com o responsável pela empresa através dos dados cadastrados em "Minha Empresa".
